# Task: Filtering & Search System

## Description
Implement comprehensive filtering and search capabilities including category filters, priority sorting, text search functionality, and the FilterBar component. This enables users to efficiently organize and find tasks in their collection.

## Acceptance Criteria
- [ ] FilterBar component with category dropdown and priority filters
- [ ] Real-time text search across task titles and descriptions
- [ ] Multiple filter combination support (category + priority + search)
- [ ] Sort functionality by due date, priority, creation date, and completion status
- [ ] Filter persistence across browser sessions
- [ ] Clear all filters functionality
- [ ] Visual indicators for active filters
- [ ] Debounced search input for performance optimization

## Technical Details
- **Implementation approach**:
  - FilterBar component with event-driven architecture
  - Debounced search input to prevent excessive filtering
  - Efficient filtering algorithms for large datasets
  - State management for active filter combinations
- **Key considerations**:
  - Maintain performance with large task collections
  - Provide intuitive filter combination logic
  - Ensure filter state persists appropriately
  - Design responsive filter interface for mobile devices
- **Code locations/files affected**:
  - `/index.html` - FilterBar component, search logic, and filter state management
